# Authing 详细配置教程

本文档详细介绍如何配置 Authing 身份认证服务，实现微信扫码登录功能。

## 前置准备
1. 已注册 Authing 账号（https://authing.cn/）
2. 已经完成项目初始化（参考 [installation.md](./installation.md)）

---

## 配置步骤

### 第一步：创建新应用
1. 登录 Authing 控制台，选择 "自建应用"
2. 点击右上角 "创建应用"
3. 填写应用信息：
   - 应用名称：dannis-authing 企业服务平台
   - 应用类型：选择 "Web 应用"
   - 认证地址：自定义一个前缀，比如 `dannis-authing`，你的完整域名就是 `dannis-authing.authing.cn`
4. 点击 "创建"

### 第二步：获取核心配置参数
创建完成后，在应用详情页可以获取到三个关键参数，填写到 `.env` 文件中：
```env
# 客户端使用的参数需要加 NEXT_PUBLIC_ 前缀
NEXT_PUBLIC_AUTHING_APP_ID=应用详情页的 "应用 ID"
AUTHING_APP_SECRET=应用详情页的 "应用密钥" # 敏感信息，不要加前缀
NEXT_PUBLIC_AUTHING_DOMAIN=你刚才设置的认证地址，比如 `dannis-authing.authing.cn`
```

> ⚠️ 重要说明：
> 1. Next.js 中只有前缀为 `NEXT_PUBLIC_` 的环境变量才能在浏览器端访问，所以客户端使用的 APP_ID 和 DOMAIN 需要加此前缀，而 APP_SECRET 是服务端敏感信息，绝对不要加前缀。
> 2. 环境变量全大写是**行业通用标准约定**，目的是和代码中的变量区分开，一目了然是配置项，不是强制性要求但强烈推荐遵循。

### 第三步：配置回调地址
1. 在应用详情页左侧菜单选择 "应用配置" → "认证配置"
2. 找到 "登录回调 URL" 配置项
3. 添加你的项目回调地址：
   - 开发环境：`http://localhost:3000/auth/callback`
   - 生产环境：`https://你的域名/auth/callback`
4. 保存配置

### 第四步：开启微信登录能力
1. 在应用详情页左侧菜单选择 "身份源管理" → "社会化登录"
2. 点击 "添加身份源"，选择 "微信" → "微信移动端"
3. 配置微信登录参数：
   - 如果你有微信开放平台账号，填写自己的 "AppID" 和 "AppSecret"
   - 如果没有，可以先使用 Authing 提供的测试身份源用于开发测试
4. 开启 "允许此身份源登录" 开关，保存配置

### 第五步：配置安全设置
1. 左侧菜单选择 "安全设置" → "CORS 配置"
2. 添加你的项目域名到允许列表：
   - 开发环境：`http://localhost:3000`
   - 生产环境：`https://你的域名`
3. 保存配置

---

## 测试配置是否生效
1. 启动项目 `pnpm dev`
2. 访问 `http://localhost:3000/login`
3. 页面应该能正常显示微信扫码登录二维码
4. 扫码后应该能正常回调并登录成功

---

## 常见问题排查

### 扫码后回调失败
- **可能原因**：回调地址和 Authing 后台配置不一致
- **解决方法**：检查 Authing 后台的登录回调 URL 是否和你项目的回调地址完全相同，包括 http/https 协议、域名、端口、路径。

### 微信登录提示 "未授权"
- **可能原因**：微信身份源配置错误
- **解决方法**：
  1. 检查微信身份源中的 AppID 和 AppSecret 是否正确
  2. 确认微信开放平台中配置的授权域名和 Authing 的域名一致
  3. 如果使用测试身份源，确认测试身份源还在有效期内

### 跨域错误
- **可能原因**：CORS 配置不正确
- **解决方法**：在 Authing 后台的 CORS 配置中添加你的项目域名，包括 http/https 协议和端口。

### 登录成功后无用户信息
- **可能原因**：权限配置不正确
- **解决方法**：检查 Authing 应用的 "返回字段" 配置，确保开启了 openid、nickname、picture、email、phone 等字段的返回权限。
